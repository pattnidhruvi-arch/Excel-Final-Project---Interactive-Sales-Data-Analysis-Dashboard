# 📊 Excel Data Intelligence Dashboard

## 📌 Project Overview

This project is an interactive Sales Data Analysis Dashboard created using Microsoft Excel.

It helps analyze sales performance, revenue, transactions, product quantity, and customer activity.

## 🛠️ Tools Used

- Microsoft Excel
- Excel Formulas
- PivotTables
- Slicers
- Charts

## 📈 Key Performance Indicators

- Total Revenue: 229,192.47
- Total Transactions: 250
- Quantity Sold: 753
- Average Transaction Value: 916.77
- Unique Customers: 50

## 📊 Dashboard Analysis

- Product Quantity Analysis
- Revenue by Category
- Region-wise Revenue Analysis

## 🎛️ Interactive Dashboard

PivotTables and Slicers help users filter sales data by region and payment method.

## ✅ Conclusion

This project demonstrates how Microsoft Excel can be used for data analysis and visualization.
